# Side Chat

A small Mac app. Highlight text anywhere, press a hotkey, and ask a side question about it in a pop-up chat. Works with Claude, ChatGPT, Gemini and OpenRouter.

This repository only hosts the downloads. Side Chat checks it for new versions and updates itself.

## Install

In Terminal (no security warning):

```bash
curl -fsSL https://github.com/roderichlee/side-chat-updates/releases/latest/download/install.sh | bash
```

Or download the `.dmg` from the [latest release](https://github.com/roderichlee/side-chat-updates/releases/latest), drag Side Chat into Applications, and allow it once in **System Settings → Privacy & Security → Open Anyway**.

Needs macOS 13 or later on an Apple Silicon Mac.

## Updates

Installed copies check for updates about once every 6 hours. Each update is signed. Side Chat refuses any download that isn't signed with the developer's key. To check right away, choose **Check for Updates…** in the menu bar menu.
